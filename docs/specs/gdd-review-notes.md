# GDD v0.1 Review Notes — 2026-08-03

Five findings from the founding review (Claude, pre-fort). The GDD is the spec; these are open questions and amendments riding alongside it. Items 3 and 5's conclusions were promoted to charter standing orders 10-12 and 14.

1. **Tier 0's result is asymmetric.** A pass is strong signal (compelling with fake numbers and no other players → only improves with real ones). A fail is ambiguous: the full design's tension comes substantially from other humans moving prices while you're committed, which scripted noise may not carry. Pre-committed reading (now standing order 14): a T0 fail triggers re-test at T2 with real counterparties before any kill decision.
2. **"Zero dials" is aspiration, not fact.** §4.7's derived NPC-firm thresholds move tuning into the derivation's parameters rather than eliminating it. Principled dials beat naked ones — but claim it honestly in public materials, because players will quote "no developer-tuned dials" back at the first coefficient change.
3. **The sim must take time as an input; never read the wall clock.** "1:1, no acceleration, ever" is a product rule, correct, and pinned in production config — but if it leaks into architecture the game is untestable (nobody playtests a 40-day transit; CI can't reach a conjunction 26 months out; disputes can't replay). With a virtual clock, the deterministic event-sourced core becomes maximally testable: golden replays, property tests, CI simulating years in seconds. Now standing order 10.
4. **The causality filter is an invariant, not a feature.** "Send each player only what has causally reached them" is mechanically testable: for every emitted message, `emission_time − event_time ≥ distance/c`. Written as a test before the code that could regress it (the /mcp-invariant lesson from Proofdelve). Now standing order 12.
5. **Live-service ops is the honest cost line.** The niche (DF/Aurora economics, subscription-shaped) aligns with the product-first small-business direction, except: a persistent single world is a live service, an ops commitment unlike Justin's other projects. Tier 0 doesn't incur it; the bill arrives at T2. Decide with eyes open then.

Competitive addendum (from the naming sweep, 2026-08-03): **oldlight.io** is building an adjacent thesis (slow async multiplayer strategy, shared persistent galaxy) and has been publicly dev-logging since ~June 2026. Differentiators to protect: real Sol system, real ephemerides, delta-v as the ladder, light-lag as market structure. Study bead filed.
